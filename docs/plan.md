# Roadmap

The template includes five adapters, per-owner native deployment, credential walkthroughs, source/destination/schedule controls, preview/enable and extension instructions.

Next acceptance work: independent-owner clone/restore, longer-running refresh/recovery tests and live account journeys for every provider. Additional connectors should demonstrate a useful pattern and follow the same onboarding, source-boundary and readback contracts.

Keep instance-specific plans, milestones and evidence in the owner's private Fulcra workspace. They do not belong in this public source tree.
