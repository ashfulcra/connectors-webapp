# Project decisions

- Separate deployment, authentication, credentials and state for each owner.
- Fulcra folders and v1 record types are content destinations; no annotations.
- Native operational persistence and scheduling are the default hosted path; PostgreSQL is optional.
- Explicit source selection and preview confirmation precede collection.
- Five adapters demonstrate different patterns; support boundaries are documented per provider.
- Credentials remain encrypted server-side. Setup uses direct official creation/console links, with explicit native-only exceptions.
- New/replacement/saved views preserve destination/schedule controls and clear navigation.
- Contributions are reviewed; updates do not silently change existing personal apps.
- MIT licensed; private operational history and real account data are excluded from public source.
