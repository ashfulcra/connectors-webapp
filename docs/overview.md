# Fulcra Connectors

A personal app for importing selected third-party data into Fulcra folders and v1 records. Each copy has its own namespace, verified owner, credentials, native state and schedule.

Start with [README](../README.md), then [setup](setup.md) and the [user guide](user-guide.md). Agents should read [AGENTS](../AGENTS.md) and the [extension contract](agent-guide.md). See [verification status](progress.md) and [operations](operations.md) for tested behavior and remaining acceptance work.
